Work 04 · Agent safety benchmark

ANI — Affective Non-Interference.

A preregistered, two-phase study of whether policy-irrelevant affect changes what LLM agents do with protected actions — and what replicates.

Phase 1 complete · Phase 2 toward ICLR 2027 Preregistered Agent safety Null result, honestly reported

Junjie Xu and collaborators · East China Normal University

When task facts, risk, permissions, and policy evidence are byte-identical, does pure emotional expression change an LLM agent's protected-action behavior? Phase 1's preregistered answer was NONE_CONFIRMED — the affect effect did not replicate. What the audit surfaced instead: an affect-independent policy-compliance fragility. Phase 2 scales the question to multi-agent composite attacks.

01

Narrowing "emotion affects models" into a falsifiable safety property

The construct is ANI — Affective Non-Interference: the protected-action projection of a trajectory (decisions, tools, parameters, environment state) must remain invariant to PIA — policy-irrelevant affect, emotional expression that adds no facts, urgency, authority, moral leverage, or help-seeking intent. Tone and empathy changes do not count as violations. The threat model is deliberately narrow: the user may only change how they express a request — never the policy, evidence, or task facts.

Phase 1 · single agent · ANI-Bench
02

An assembly defect, two findings, one honest null

The pilot phase reported +29–43pp "affect effects" from re-realized PIA text, and a held-out preregistered confirmation initially agreed (+36.8pp). Then the audit chain took it apart: a policy-None sub-matrix showed the runner was silently self-composing compliance rules; the confirmatory corpus returned NONE_CONFIRMED; a policy-swap factorial located +41.8pp on the policy-delivery factor while PIA stayed at ≈0pp [−2.0, +2.1]. Blind screening and preregistration had both failed to stop an engineering artifact — so "policy delivery assertion" (every agent system prompt now carries a policy_hash, missing = abort) was written into Phase 2's hard gates.

Real finding · fragility 282 / 288

Escalation-state violations — the agent executed where policy demanded escalation — plus ≈14% unauthorized execution in explicit DENY states. Nothing to do with emotion; everything to do with compliance plumbing.

Real finding · null ≈ 0 pp

PIA / filler contrast under both policy-delivered and policy-missing conditions (D3-adjusted Δ −0.0077, robust direction). A null that survives correction is a result — not a footnote.

Phase 2 · multi-agent · toward ICLR 2027
03

Composite attacks: expression slot × evidence slot

Phase 2 rebuilds the question as a matched dual-slot 2×2 — the same case, the same injection site: expression (neutral filler vs PIA) crossed with evidence (clean control block vs a fixed misinformation assertion). The estimand is the additive interaction I = (q₁₁ − q₁₀) − (q₀₁ − q₀₀): does in-scenario emotion conditionally amplify misinformation? Every misinformation payload carries an authority-source contract, an uncoverable-rule clause, and a conflict→ESCALATE oracle — so legitimate update paths can never be scored as attacks. Six evidence goals (C1–C6) define success: positive, negative, equivalence, and inconclusive outcomes all have legal interpretations, and a null is never dressed up.

04

Claim boundary & governance

✓ Established

  • A machine-checkable policy corpus (32/32 validation, 16/16 label re-derivation) with build gates
  • Preregistrations frozen in git before the corresponding runs; held-out confirmations stated in advance
  • NONE_CONFIRMED for affect generalization — plus a bounded, affect-independent compliance fragility
  • A governance chain: supervision log with five AI-auditor dispatches, runner change log C1–C8, per-model cost ledger
  • Institutionalized fixes: policy-hash delivery assertion as a Phase 2 hard gate

✗ Explicitly not claimed

  • That affect never changes agent behavior — Phase 1 establishes a bounded null on one frozen corpus
  • That Phase 1 answers the question — it is a conditional baseline (frozen protocol, six models, D3-adjusted)
  • Persuasion, urgency, or authority claims as affect — those are new evidence and are excluded from the main experiment
  • Dialogue-level affect transmission results — those belong to prior work (CoA) and are cited, not claimed
  • An ICLR 2027 submission this cycle — completion, not calendar, sets the venue
