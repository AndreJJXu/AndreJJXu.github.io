作品 03 · 理论先行研究计划

反事实证据保真度。

CEF——选择性 LLM 评估器的一种可观察行为属性，作为一个 24 阶段的探索性研究计划推进，目标 ICLR 2027。

探索性项目 · 目标 ICLR 2027 行为测量 信息论 机制搜索

许俊杰 及合作者 · 华东师范大学

保真度应当从行为中测量，而不是靠感觉：当评估器对非决定性的干扰线索保持条件稳定、对决定性证据做出方向正确的响应、 并且不通过弃答 / 覆盖塌缩 / 合同失败 / 技术性缺失获得任何便宜时，它才具备 反事实证据保真度（CEF）。 一个 24 阶段的项目检验这一构念——以及一个在四元组审计中拿到 1.0000 的候选机制。

42,240阶段 1–15 的形式化实验条件
2,040 万历史证伪链消耗的 API tokens
5 次运行独立收敛到身份条件化归一化证据状态
112保持通过的测试，含治理检查
01

一个有三条要件的构念

"评估器有没有在用证据？"这样问是无法证伪的。CEF 把它分解为三条共同可观察的行为要求——每一条都可以独立审计，也都可以独立失败。

一

条件稳定性

当非决定性的干扰线索（如严重度数字）变化时输出保持稳定——响应应跟随证据，而不是元数据。

二

方向正确性

当决定性证据被干预时，做出方向正确的响应——这是构念中"反事实"的一半。

三

没有免费午餐

不通过弃答、覆盖塌缩、合同失败或技术性缺失获得任何表面收益。

02

一个经得起消融的机制候选

五次正向全矩阵运行（v13 / v17 / v19.1 / v22 / v24）独立收敛到同一个最小机制：身份条件化归一化证据状态。v23 必要性消融支持归一化状态通道；阴性审计（v20 / v21）界定了设计不起作用的边界。工作方法名为保真感知证据瓶颈（Fidelity-aware Evidence Bottleneck）——在完成新颖性审查之前保持暂定。

1
选择器——身份锁 从完整数据包中，精确给出一个具名记录、逐字内容引用、证明该记录归属的逐字绑定引用，以及归一化的目标信号。
2
归一化——硬切 仅使用同源内容，投影到有限的 {存在, 不存在, 无法判定} 状态；切断所有原始上下文与干扰文本。
3
读取器隔离——确定性合同 读取器只看到被选身份与目标信号，服从确定性决策规则，并提供按通道归因的失败分析。
03

探索性结果，按探索性报告

四元组审计将每个条目与一次干扰干预、一次证据干预交叉，每格重复三次。候选机制在两个任务族上都把错误率降到零。这些数字不能确立的东西同样重要：它们是合成的、基于提示的发现结果，不是一个成品训练方法的证据。

GPT-5.4 · 候选机制 vs 基线 0.8333 → 1.0000

临床三记录任务的四元组通过率；在非临床运营任务上为 0.8299 → 1.0000——且无弃答、无覆盖损失。一项来源可解析性挑战还成功区分了正确的"无法判定"行为与选择性遮蔽。

GPT-5.5 · 诚实的零结果 1.0000 = 1.0000

在 GPT-5.5 上，修复后的证据先行基线与候选机制都拿到了满分，因此跨模型的相对优势仍未得到确认——我们把它作为零结果报告，而不是埋起来。

04

主张边界

✓ 已确立

  • CEF 构念：三条共同可观察的行为要件及其失败模式
  • 四元组审计设计与聚类自助不确定性（10,000 次重采样）
  • 五次收敛运行 + 支持"归一化状态通道"的必要性消融
  • 带自动化主张验证的理论章节——测量、统计、信息论前沿、通道分解

✗ 明确不主张

  • 任何评估器具有一般性不变性、忠实性、安全性或临床有效性
  • 探索性收益确立了跨独立任务的一般性改进
  • CEF 揭示了模型的内部推理或因果机制
  • 姊妹 AAAI 项目的封存证据能确认本项目任何内容——它只是外部动机，只读引用
  • 预注册或确证性可复现——Phase 0 v2 工程暂缓
