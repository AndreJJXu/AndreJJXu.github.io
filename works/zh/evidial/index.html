作品 02 · 基准与测量

EviDial.

Evidence + Dialogue——一个用于评估"LLM 评委如何评判抑郁对话"的面板可评估性框架。

撰写中 · ICLR 2027 评估基准 LLM 评委面板 临床对话

许俊杰 及合作者 · 华东师范大学

一段抑郁对话的发言，究竟在什么条件下才是可评估的？ EviDial 用五协议 LLM 评委面板替代昂贵的人工金标准—— 1,910 次裁定、100% 覆盖、零现金成本——并给出关键证据： 协议多样性堪比模型族多样性（有效裁判数 1.59 vs 1.56）。

01

面板可评估性，而不是借来的金标准

临床对话评估通常默认人工金标准的存在。按 3,200 个锚定裁定点估算，约 ¥175k 与 4–6 个月的成本把大多数实验室挡在门外。EviDial 换了一条路：被测量的构念是面板可评估性（panel-assessability）——一个经干预校准的五协议评委面板，能否对一段发言给出稳定、可审计的裁定——并且论文明确不主张面板共识与临床专家判断等价。

冻结的 suffneg_pass 修复说明了这套机制为什么重要：一个恒阳性的系统在旧指标下拿到完美的 72/72 = 1.0，而在联合指标下恰好是 0/72 = 0.0。冻结容差下 8/8 的捕获保持不变。

02

来自 3,000+ 次盲态裁定的发现

M1 全量面板交付了 1,910/1,910 次裁定、100% 覆盖、零现金成本；M2 分层扩展追加 205 段 × 5 协议 = 1,025 次。试点线确立了定量核心：同底座模型的协议面板有效裁判数达 1.59，而五族模型面板为 1.56——协议多样性是模型多样性的可行替代。

03

主张边界

✓ 已确立

  • 冻结的任务合同、证据状态模式与指标规范，配有自动化检查器
  • 1,910 + 1,025 次盲态面板裁定，满覆盖、冻结协议、盲态对话文本
  • 分离绑定特有干扰失败的机制实验
  • 口径统一的结果清单（84 行）与冲突报告，三道门全绿
  • 独立人工标注工具链、标注手册与成本模型，随时可启动

✗ 尚不主张

  • 人工锚定金标准——2–3 名标注者的研究（约 196 人时）已设计但未执行
  • 五方法评委的真实比较——阻塞于 API 凭证
  • 面板共识与专家临床判断的等价性
  • 会议录用——内部模拟评审分数是工程反馈，不是结果
  • 一项早期构念效度发现已被主动撤回：单调上升的是症状负担，而非可评估性
